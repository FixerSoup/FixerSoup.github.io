CUSTOMER SEGMENTATION & CHURN PREDICTION WITH RECOMMENDATION AND RETENTION ANALYSIS

KEY IDEA

Many Beginner data scientist/analysis face problems and issues while building a production level churn system Here's a easy to understand and use static customer segmentation churn predicting with recommendation and retention analysis project which provides easy to understand and usable stuffs to integrate to it their own systems.

SOFTWARE TOOLS USED

Python · Pandas · Scikit-learn · SQL · Jupyter Notebook · Random Forest Classifier · KMeans Clustering · markdown · Matplotlib · Seaborn

APPROACH

  • 1. Started by exploring the dataset nicely understanding the patterns,anomalies.
  • 2. Completed Exploratory Data Analysis.
  • 3. Cleaned the dataset.
  • 4. Split the data into train and test sets.
  • 5. Trained RandomForestClassifier on the dataset for churn prediction and saved the model.pkl file for future reference.
  • 6. Trained K-Means Clustering on the dataset for customer segmentation to 4 clusters based on top features.
  • 7. Feature Engineered on the outcomes and added new features to the existing data to predict churn based on all the relevant features.
  • 8. Made a .md file for a nice technical report.
  • 9. converted it to a .pdf file for easy view and saved to the disk automatically.

TECHINICAL DETAILS

  • I have used Hugging Face Dataset for my project
  • Explored the dataset, by understanding rows, column ,its datatypes , nuerical columns , categorical columns , size , shape of the data
  • Cleaned it , removed duplicates, handled null spaces with median() for numerical , mode() for categorical columns and texts for special characters like '?','-'.Fixed the datatypes like datetime for date column,Handled outliers
  • Split the data into training and testing set with test size 40% and training size 60%
  • Standardised the data by using StandardScaler()
  • Trained Random Forest Classifier on the data by 200 estimators and KMeans on 4 cluster
  • Performance Metrics
    • Accuracy : 0.93
    • Precision : 0.938
    • Precision (Stayed) : 0.93
    • Precision (Churned) : 0.94
    • Recall (Churned) : 0.94
  • Saved this whole model as churn_prediction_pipeline.pkl file
  • Used tool calling feature to an AI model (gemini-3.5-flash-lite) through the saved model details for accurate prediction and analysis with recommendation by simple easy questions from the users
  • Saved the whole output to a .md file which gets saved to a .pdf file for easy access

MY LEARNINGS

  • How to segmentize customers based on top useful features.
  • How to split the data to training and testing set
  • How to train RandomForest Classifier and KMeans Clustering ML algorithms
  • How to use tool calling i.e. function calling through an AI model

VISUAL PRODUCT SEARCH ENGINE

KEY IDEA

Frustrated by text-based search limitations in fashion clothes searches, I developed a computer vision-powered product search system that allows users to find similar items using images as well as texts.This project tackles the "I know it when I see it" problem—when customers can describe what they want visually but struggle to articulate it in text queries.

SOFTWARE TOOLS USED

Python · google-genai · streamlit · fastAPI · Uvicorn · CLIP model · Docker · Qdrant(Vector Database)

APPROACH

  • 1. I used hugging_face_fashion_mnist_data .
  • 2. Used Open AI's CLIP Model to embed those image data into vectors with 512-Dimensions and stored in a vector database (Qdrant)
  • 3. Finished creating a user level deployed website using streamlit for frontend, uvicorn for backend and FastAPI for web frameworks
  • 4. Now,Whenever a user inputs a image or a text ,first its vector embedding is generated via CLIP model and then semantic searching is performed in the database with the 10 most similar images which have very little difference
  • 5. I shipped all the dependencies inside a docker file and made it easy for users to install and use it via docker

TECHNICAL DETAILS

  • I cloned the data from the source using load_dataset
  • Created a client connection to the Qdrant database and a collection(folder) in it named as 'Products'
  • Encode each data i.e. generated vector embeddings and pushed those embeddings to the database
  • For encoding I have used Open AI's CLIP Model(clip-vit-base-patch32), with vector size = 512
  • I used user defined methods to embed images and texts separately for easy embedding
  • After storing each vector the database smartly creates a network of points.
  • Created a streamlit deployed frontend for simplest and easiest usage of the project
  • I have containerized all the dependencies and requirements to a single docker compose to make shipping and installation easy and fast

MY LEARNINGS

  • How to deploy projects via Streamlit
  • Use Docker for containerization and shipping with all the dependencies involved
  • Work with uvicorn web Server and fastAPI frameworks
  • How vector databases work based on semantic searching and mapping
  • How to create vector embeddings from Open AI's CLIP model
